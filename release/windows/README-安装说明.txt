Codex Auto Resume 0.8.0 - Windows x64 安装说明
================================================

适用环境
--------
- Windows 10 / 11 64 位系统
- 电脑上已安装并至少启动过一次 Codex App
- 纯绿色安装，不需要管理员权限
- 不需要预装 Go、Node.js 或其他开发运行环境

安装步骤
--------
1. 先把整个 ZIP 压缩包解压到一个普通文件夹中（切勿直接在压缩包预览窗口里双击运行）。
2. 先完整退出 Codex App，再双击“安装.cmd”。安装器会自动校验包完整性并启动后台守护服务。
   如果 Codex 仍在运行，会弹出中文提醒；保存工作并退出后点击“重试”即可继续。取消或等待超过五分钟会安全结束，不会强制关闭 Codex。
3. 等待黑色控制台窗口显示“Installation succeeded”后按任意键关闭。
4. 安装完成后，Windows 右下角通知区域会出现独立的 Codex Auto Resume 托盘图标。
5. 检查连接状态与恢复通道：
   - 双击托盘图标打开“设置”窗口查看当前状态：
     * 【推荐 / 新版 Codex】：若状态显示“Codex 已接入官方恢复通道”，说明您的 Codex 支持原生 IPC 通道。无需进行任何额外设置，直接正常打开 Codex 即可享受自动静默恢复！
     * 【兼容 / 旧版 Codex】：若状态显示“Codex 未接入共享后台”，如需开启静默恢复，请在托盘设置中勾选“启用共享后台”并通过健康检查；之后完整退出 Codex，通过解压目录下的“安全启动Codex.vbs”（或启动管理器中的“Launch Codex safely”）启动 Codex 即可。
6. 验证是否安装成功：
   双击右下角托盘图标打开桌面客户端，若能正常显示心跳健康与队列状态，即代表就绪！

版本特性说明（0.8.0）
----------------------
0.8.0 是一次大版本更新，包含以下新能力：
- 配额重置感知恢复：任务撞上用量上限（如 5 小时窗口、每周窗口）时，不再盲目重试，而是等待服务器报告的重置时间，到点后自动恢复原任务；额度耗尽、消费上限等无法自动跨越的情况会标记为“需要关注”，绝不无限重试。
- 订阅窗口与付费额度分开统计：订阅配额与购买积分各自独立取证，避免互相污染；已建立恢复等待的窗口不会被重复采信。
- 全新桌面客户端：双击托盘图标打开独立窗口，实时查看任务队列、倒计时与账户配额；支持中英文一键切换与主题持久化，关闭窗口不影响后台守护服务。
- 会话目录：桌面客户端可浏览历史 Codex 会话（真实标题、按项目目录过滤、多段内容自动拼接），并支持从任务队列一键跳转到对应会话。
- 本机管理接口：所有客户端通过 127.0.0.1 回环管理接口读取状态，每次启动使用独立令牌，数据不出本机。
- 全新托盘图标与提醒：圆角品牌方块加状态染色重试弧线，任务恢复、需要关注等状态变化一目了然。
保留 0.7.12 的官方 IPC 恢复改进与安装器可靠性修复。

启动管理与紧急停用
------------------
- 双击“启动管理器.cmd”：
  打开独立的图形管理窗口（无多余黑框），可查看真实的开机启动命令、supervise 监督进程、心跳、共享后台与端点状态；支持一键启闭开机自启、启动/停止守护服务。
- “安全启动Codex.vbs”：
  仅在后台身份和健康检查通过后，将本地端点安全传递给当前启动的 Codex；如果后台异常或关闭，会自动回退到官方直连模式，绝不修改 Windows 全局永久环境变量。
- 双击“安全停用.cmd”：
  一键紧急回退脚本。如果 Codex 启动异常，双击此脚本会立即停用共享后台、清理插件自身的启动项与本地端点，让 Codex 彻底回到纯净官方环境。
  （注：本脚本仅清理 Codex Auto Resume 自身的注册表与进程，绝不会删除任何聊天记录或 API 密钥）。

托盘设置指南
------------
双击右下角托盘图标即可打开设置窗口：
- 任务队列监控：实时查看当前处于等待重试或活跃状态的任务，以及最近一次倒计时。
- 双重安全防线（防死循环与防配额耗尽）：
  * “本次故障恢复”上限（默认 15 次，最高可调至 1000 次）：限制同一段故障期间的最大重试总次数。
  * “连续无进展”上限（默认 5 次，最高可调至 100 次）：若重试未产出任何可见助手回复或工具调用，达到上限即主动停止并标记该任务，防止无限空耗 Token。
- 等待退避策略：
  支持“固定间隔”、“等差线性递增”以及“翻倍指数递增”，可自定义首次等待、步长与最大等待封顶时间。产生可见回复后，连续计数自动清零并重置等待时间。
- 界面语言：支持一键切换简体中文与英文。
- 提醒说明：托盘中的通知开关仅控制插件达到重试上限时的系统气泡提醒。Codex 自带的“ChatGPT finished a turn”弹窗属于主程序行为，如需关闭可在 Codex“设置 > 常规 > 通知 > 轮次完成通知”中选“从不”。

桌面客户端
----------
双击托盘图标打开桌面客户端：
- 可查看当前任务队列、倒计时、一键立即重试（Retry Now）或取消重试。
- 支持全局暂停自动重试。
- 可修改后备重试文字（默认“继续”）。在普通对话中，插件优先执行“原地静默续接（无新增用户泡泡、不重发旧消息以防重复工具副作用）”；只有当本地 Codex 不支持静默续接时，才会发送该后备文字。
- 目标模式（Goal Mode）原生恢复：支持 Codex 目标模式自动恢复，且严格遵循用户/AI 的主动暂停状态，暂停期间绝不擅自恢复。

卸载与彻底清理
--------------
1. 标准卸载：
   双击解压目录下的“卸载.cmd”，即可自动停止后台服务、移除开机启动项与 Codex 插件注册。默认会保留您的重试配置、历史状态和运行日志，以便日后重新安装继续生效。
2. 彻底删除数据：
   如需连同所有运行数据与日志一并彻底清除，请在解压目录下打开 PowerShell 运行：
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\uninstall-release.ps1 -RemoveData

关键文件与目录说明
------------------
- 插件源码目录：%USERPROFILE%\plugins\codex-auto-retry
- 守护进程与运行状态：%LOCALAPPDATA%\CodexAutoRetry
- 运行日志路径：%LOCALAPPDATA%\CodexAutoRetry\logs\daemon.log
- Codex 插件注册缓存：%USERPROFILE%\.codex\plugins\cache
- 开机自启注册表项：HKCU\Software\Microsoft\Windows\CurrentVersion\Run\CodexAutoRetry

安全与隐私说明
--------------
- 安装程序会先对照 SHA256SUMS.txt 校验安装包中所有二进制与脚本的哈希值。
- 本工具为完全本地运行的开源工具，仅解析任务生命周期状态码，绝不读取、保存或上传任何用户消息、代码内容、工具参数或 API 密钥。
- 目前尚未购买昂贵的商业代码签名证书，因此安装时 Windows SmartScreen 可能提示“未知发布者”，请认准官方 GitHub Releases 发布的 SHA-256 校验和。

常见问题排查
------------
- 安装器提示找不到 Codex：请先正常启动一次官方 Codex App 并进入主界面，关闭后再运行“安装.cmd”。
- 安装后在 Codex 中看不到插件：必须在 Codex 中“新建一个任务/会话”才能加载新插件；已经在进行的旧会话不会自动重新读取插件列表。
- 提示“请重启一次 Codex”：完整退出 Codex 软件后重新打开即可。
- 永久失效的账号登录：若账号被封禁或登录已彻底过期，仍需在 Codex 中重新扫码/登录，插件无法绕过账号身份验证。
